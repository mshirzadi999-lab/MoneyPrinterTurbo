# THE Character — مرجع تنها و رسمی شخصیت شورت‌ها

**وضعیت:** تأییدشده توسط مهدی — ۲۰۲۶-۱۱-۱۰ («همین عالیه»)
**فایل مرجع:** `character.py` در همین پوشه (تابع `draw_character`) — استخراج عینی از تست جنگل اصلی (`original_make_hybrid.py`).

## قانون طلایی
این شخصیت **از صفر بازطراحی نمی‌شود** — نه با Manim، نه با هیچ ابزار دیگری.
هر توسعه‌ای (ژست، حالت، حرکت تازه) روی همین کد انجام می‌شود.
طرح‌های دیگری که رد شدند: نسخه Manim عینکی/پیرهن سبزآبی (ابزار repo)، شش مدل خطی مقایسه‌ای ۲۰۲۶-۱۱-۱۰، استیک‌من راه‌رونده و صحنه شب — همه رد شده‌اند؛ برنگردند.

## مشخصات طراحی (از روی کد)
- بوم: 720×1280، سوپرسمپل ×۲
- سر: دایره سفید، دورخط مشکی (پهنای ۶)، شعاع ۷۸ — چشم نقطه‌ای مشکی (پلک‌زدن دوره‌ای)، ابرو خطی، دهان قوسی ساده
- تنه: خط ضخیم گرد به رنگ قرمز گرم — SHIRT = (196, 58, 44) — پهنای ۶۴، با بیضی شانه؛ حجم‌دار و یه‌تیکه، **نه خط باریک**
- **آستین = بازوی بالایی:** قطعه شانه تا آرنج هم‌رنگ پیراهن (پهنای ۲۶)؛ ساعد سفید (۱۵)؛ دست دایره سفید با دورخط مشکی — دست و آستین یکپارچه حرکت می‌کنند
- شلوار/پاها: سرمه‌ای تیره — PANTS = (38, 44, 66) — پهنای پا ۱۷؛ کفش بیضی مشکی
- سایه نرم زیر پا روی زمین
- حالت‌ها (تایم‌لاین ۵ ثانیه‌ای اصلی): idle (لبخند + پلک) → notice → shock (دست‌ها بالا، دهان O، قطره عرق آبی) → worried (ابروی کج، دهان وارونه)
- API کمکی: `character_layer("idle" | "shock" | "worried")`

ویدیوی مرجع: `~/workspace/your_files/hybrid-test/hybrid-test-5s.mp4`
